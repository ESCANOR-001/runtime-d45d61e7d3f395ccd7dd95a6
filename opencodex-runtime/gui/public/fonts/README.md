# Dashboard fonts

The bundled `google-sans-*.woff2` files are Google Sans subsets obtained from
the Google Fonts API on August 20, 2026.

- Family: Google Sans
- Source: `https://fonts.google.com/specimen/Google+Sans`
- Google Fonts metadata marks the family as open source.
- Included scripts: Latin and Cyrillic
- Included weights: 400, 500, 600, and 700

The dashboard retains system and Noto fallbacks for scripts that Google Sans
does not cover, including Chinese, Japanese, and Korean.
